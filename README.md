# SASUKEアイドル予選会データブック

SASUKEアイドル予選会の大会レビュー・能力値一覧・選手名鑑・大会記録をまとめた非公式ファンサイトです。

## 公開URL

https://cola-labs.github.io/idol-qualifier-databook/

## ページ構成

- `index.html`：トップページ
- `42/index.html`：第42回大会データブック
- `43/index.html`：第43回大会データブック
- `records/index.html`：大会記録・統計データ
- `favicon.ico` / `favicon-*.png`：favicon
- `og-image-general-v2.png`：SNS共有用OGP画像

## 更新メモ

- 各大会ページはフォルダ単位で管理する
- 例：第44回大会を追加する場合は `44/index.html` を作成
- トップページの大会一覧に新大会へのリンクを追加する
- 大会記録ページにも必要に応じて記録を追加する

## 注意事項

このサイトは非公式ファンサイトです。  
掲載内容には独自の分析・解釈を含みます。
